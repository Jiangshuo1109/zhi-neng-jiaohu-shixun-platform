# 智能交互实训室平台（前端）

Vue 3 + Vite + TypeScript + Vue Router + Pinia + Element Plus 实现的 B/S 管理端，数据全部来自 `src/mock/`。

## 运行

```bash
cd /workspace/智能交互实训室平台/app
npm install
npm run dev -- --host 0.0.0.0 --port 5173
```

构建：

```bash
npm run build
```

浏览器访问：`http://localhost:5173`

## 登录说明

登录页可选择角色账号，密码均为 `123456`：

| 账号 | 角色 |
|------|------|
| sysadmin | 系统管理员 |
| labadmin | 实训室管理员 |
| centeradmin | 中心管理员 |
| teacher | 教师 |
| student | 学生 |

也可在顶栏或「我的」页随时切换账号。建议流程：教师提交预约 → 切换实训室管理员一级审核 → 切换中心管理员终审。

## 功能模块

- **工作台**：待办、消息、快捷入口（按角色）
- **基础数据**：组织、用户、角色权限、日志、校历节次、消息、实训室用房、授权应用
- **开放预约**：开放管理/设置（多规则）、时间表状态色、申请、多级审核、进度节点、记录
- **实体实训**：学生任务/步骤资料/拍照/求助/报告；教师在线监管、实时画面、远程协作（语音/冻屏/激光笔/抓图/画板/共享）、历史回看、报告模板、分组教学、教学分享（链接/二维码）、任务安排、人工+AI 评分
- **我的**：资料、账号切换、消息设置

窄屏底部 Tab；宽度 ≥ 1024 为左侧栏 + 顶栏。
